# Simply Green and Garden Spray Website

A minimal customer-facing website created to move a paper-only lawn care business into a small digital presence.

This project was built for a long-running local service business that does not rely on advertising, search traffic, or online expansion. The goal was not to create a sales-heavy website. The goal was to create a simple digital reference point where existing customers can view available services, understand program options, and contact the business more easily.

This was also my first full web development project where I handled the domain setup, hosting, file structure, and live deployment process myself.

## Overview

Simply Green and Garden Spray is a small informational website for an existing lawn care and garden spray company.

The site keeps the business model simple. It gives current customers a clean place to check services without replacing the company’s personal, phone-based workflow. The design focuses on clarity, low maintenance, and a direct customer experience.

## Features

* Mobile-first website layout
* Custom service program cards
* Additional services section
* Simple contact section
* Click-to-call phone link
* Email contact link
* Business logo integration
* Custom domain setup
* GitHub Pages hosting
* HTTPS configuration
* Lightweight HTML, CSS, and JavaScript structure
* Minimal public-facing design for existing customers
* No heavy advertising language
* No search-growth strategy
* Built around a small company that wants a basic digital reference point

## What I Learned

* How to turn a paper-only business into a small digital presence
* How to structure a simple service website around existing customer needs
* How to manage a custom domain for the first time
* How DNS, HTTPS, and GitHub Pages work together
* How to design a site that supports a business without changing how it operates
* How to keep content practical instead of making the site feel like an advertisement
* How to build for trust, clarity, and low maintenance
